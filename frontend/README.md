# Base44 App


This app was created automatically by Base44.
It's a Vite+React app that communicates with the Base44 API.

## Running the app

```bash
npm install
npm run dev
```

## Building the app

```bash
npm run build
```

For more information and support, please contact Base44 support at app@base44.com.
## Accessibility checks

### Run automated accessibility guard

```bash
npm run a11y:check
```

Pass definition: **0 serious/critical findings**.

### Run Lighthouse manually (recommended key pages)

1. Start app locally (`npm run dev` or `npm run preview`).
2. Open Chrome DevTools → Lighthouse.
3. Run on:
   - `/`
   - `/Book`
   - `/MyAppointmentsPage`
   - `/Admin`
   - `/accessibility`
4. Target accessibility score: **high score** (ideally 95+), and no blocking issues.
